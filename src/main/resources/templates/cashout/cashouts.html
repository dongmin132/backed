Refund relay

  • Every few seconds The relay sends pending and in-doubt legs to PayPal every few seconds, each with its own stored request id.
  • Declined A declined leg is not retried and its amount goes back to the balance.
  • PayPal error A 5xx is retried later with the same request id; after five tries the leg is held as in doubt, never returned to the balance, because a 5xx does not prove the refund did not happen.
  • Unknown outcome An unknown outcome is re-sent with the same request id, which PayPal answers with the original refund if it already happened.
