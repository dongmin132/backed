Sending refunds

  • Every few seconds Backed sends waiting refunds to PayPal every few seconds, each with its own request id, so none is paid twice.
  • Declined PayPal said no. We don't try again, and the money goes back on the balance.
  • PayPal error We try again with the same request id. After five tries it waits for a person, and the money stays off the balance, since the refund may have gone through.
  • No answer We ask again with the same request id. If the refund already happened, PayPal sends back that same refund.
